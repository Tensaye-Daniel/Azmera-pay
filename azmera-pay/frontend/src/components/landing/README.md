# Landing sections

Marketing sections composed by `pages/public/LandingPage.tsx`, in render order:

Hero, About, HowItWorks, BuyerSection, SupplierSection, AgentSection, TrustSection, CTASection.

Each section carries an anchor id (`#home`, `#about`, `#how-it-works`, `#buyers`, `#suppliers`, `#agents`, `#why-us`, `#cta`) used by the Navbar and Hero/CTA buttons.
