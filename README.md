## Project Description

Azmera is an agricultural marketplace for Ethiopia that connects farmers, agents, suppliers, and buyers. Its purpose is to make it easier for farmers, including those on basic phones, to request inputs and find suppliers who can provide them. The intended workflow is **REGISTER → REQUEST → MATCH → CONNECT → AGREE → TRADE**.

## Main Features

- **Agent registration of farmers** through the agent dashboard, with unique account numbers and duplicate validation
- **USSD access for farmers** on basic phones, with English and Amharic menus
- **Farmer input requests** created through USSD sessions
- **Supplier listings and Shop Setup** managed through the supplier dashboard
- **Deterministic matching** of farmer requests to eligible supplier listings, with a ranked match view
- **Phone-based accounts with roles** and JWT authentication
- **Privacy protection** for farmer contact details until a supplier accepts
