# Shared UI

- `Reveal.tsx` - scroll-reveal wrapper (IntersectionObserver)
- `icons.tsx` - inline SVG icon set
- `Field.tsx` + `field-context.ts` - accessible label/error wrapper and its context
- `control.ts` - shared form-control styling
- `TextInput.tsx`, `Select.tsx`, `Textarea.tsx` - themed form controls
- `PasswordInput.tsx` - password field with show/hide toggle
- `FileUpload.tsx` - upload control with image preview
- `ProgressSteps.tsx` - multi-step progress indicator
- `Button.tsx` - button with variants and loading state
- `Notice.tsx` - inline alert/notice banner
- `LegalDialog.tsx` - accessible modal dialog (terms / privacy)

More primitives (Card, ...) come later.
